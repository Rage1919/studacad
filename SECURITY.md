# Security policy

Please report suspected vulnerabilities privately through GitHub's **Security → Report a vulnerability** flow for this repository. Do not include credentials, identity documents, financial details, lesson messages, or other personal data in a public issue.

Include the affected URL or component, the impact, safe reproduction steps, and whether you believe user data or credits are at risk. Studacad will acknowledge a complete report as soon as operationally possible, contain active exploitation before routine development, and coordinate disclosure after a fix is available.

Public GitHub issues are appropriate for ordinary defects that do not expose data, authorization, credits, private resources, credentials, or service availability.
